# simple-network-troubleshooting-toolkit
OVERVIEW
This showcases the basic use of windows command prompt for network troubleshooting diagnostics.
The objective of these commands is to know how they work, interpret their outputs, and identify network connectivity.

# TOOLS USED
- Windows command prompt
- Windows 11

# COMMANDS USED
-----------------------------------------------------------------------------------
ipconfig                Display IPs
ipconfig /all           Display all detailed IPs, network configuration
ping                    Tests network connectivity
tracert                 Traces the route to a destination
nslookup                Checks DNS resolution
ipconfig /flushdns      Clear local DNS cache


# LEARNING OBJECTIVES
- Understand basic IP addressing and network configuration
- identify the purpose of windows networking commands in command prompt
- practice basic network connectivity troubleshooting
- understand DNS resolution and its role and purpose in networking
- document troubleshooting procedures and command outputs

# PRIVACY AND SAFETY MATTERS
This repository's IP addresses, domain examples, and network configurations are all sanitized outputs or sample values. There is no deliberate sharing of private or personal network information.
